Privacy Policy

Last updated: September 8, 2026

Drive Copier Personal is a personal desktop application used to manage file transfers between Google Drive accounts.

Google User Data

Drive Copier Personal accesses Google Drive data only after the user explicitly authorizes the application through Google OAuth.

The application uses this access solely to perform Google Drive operations requested by the user, including browsing, copying, moving, and managing files and folders.

Data Storage

OAuth credentials required to maintain the user's Google authorization are stored locally on the user's computer.

Drive Copier Personal does not operate an external server for collecting or storing Google Drive file contents.

Data Sharing

Drive Copier Personal does not sell Google user data or share Google user data with third parties.

Revoking Access

Users may revoke the application's access to their Google Account at any time through their Google Account security settings.
