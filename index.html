Drive Copier Personal

Drive Copier Personal is a personal desktop application for managing file transfers between Google Drive accounts.

Features

  • Copy files and folders between Google Drive accounts
  • Move files and folders between Google Drive accounts
  • Resume interrupted transfers
  • Support multiple Google accounts

Google Drive Access

The application accesses Google Drive only after the user explicitly authorizes access through Google OAuth. Google Drive data is used only to perform file operations requested by the user.
